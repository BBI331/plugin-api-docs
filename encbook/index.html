도감 플러그인 가이드

EncBook 3.0 — 아이템 수집 도감 + 카테고리·진척도 보상

요구 환경

  • 필수 : Paper 1.21.4 이상 (Spigot/바닐라 미지원) · Java 21 이상
  • 필수 : ItemsAdder 또는 Nexo 중 하나 (유료) — 둘 다 없으면 플러그인이 비활성화됩니다
  • 선택 : Vault + 경제 플러그인 (EssentialsX 권장) — 등록·완료·진척도 보상금 지급에 사용

스크립트 버전(도감 2.x)과 달리 Skript 및 애드온이 필요하지 않습니다. 데이터는 자체 데이터베이스에 저장되어 도감을 열 때 파일을 읽지 않아 빠르게 동작합니다.

설치

  1. encbook.jar 를 서버의 plugins 폴더에 넣습니다.
  2. 서버를 시작(재시작)합니다 — ItemsAdder(또는 Nexo) 콘텐츠가 자동으로 설치되고, 콘솔 안내에 따라 /iareload 후 /iazip(Nexo: /nexo reload)을 실행하면 반영됩니다. 리소스팩 재생성은 서버 전체 콘텐츠에 영향을 주는 작업이라 직접 실행하도록 되어 있으며, config 의 콘텐츠 자동 반영 을 true 로 바꾸면 자동 실행됩니다.
  3. 리소스팩 재적용 후 /도감 으로 확인하면 끝!
업데이트 : 새 jar 로 교체하고 재시작하면 콘텐츠·설정이 자동 갱신됩니다. 직접 수정한 콘텐츠 파일은 덮어쓰지 않고 보존합니다. PlugMan 리로드도 안전합니다.

카테고리 설정

config.yml 의 카테고리 아래에서 1번~5번 카테고리를 각각 설정합니다. 수정 후 /도감 리로드 로 즉시 반영됩니다.

항목설명
이름카테고리 표시 이름 (색코드 & 사용 가능)
이름만 인식true 면 로어를 무시하고 아이템 이름만 비교합니다 (물고기 크기 로어 대응)
페이지 수이 카테고리의 페이지 수 (1~9, 권장 5 이하)
소모 없이 등록true 면 아이템을 가져가지 않고 보유 확인만으로 등록합니다
활성화false 면 카테고리가 잠기고 진입할 수 없습니다
완료 방송카테고리 완료 보상 수령 시 전체 방송 여부
비비의 깃펜 사용 가능 여부false 면 이 카테고리에서는 깃펜으로 해금할 수 없습니다 (깃펜도 소모되지 않음)
비비의 깃펜 : 아이템을 보유하지 않아도 슬롯을 해금하는 소모품입니다. 희귀 아이템이 모인 카테고리처럼 깃펜으로 건너뛰면 안 되는 곳은 비비의 깃펜 사용 가능 여부 를 false 로 두세요.

관리자 권한 노드 : encbook.admin (기본값 OP)

기존 스크립트(도감 2.x)에서 데이터 이전

기존에 도감 스크립트(2.2 ~ 2.4 Beta)를 사용했다면, 같은 서버에서 명령어 한 번으로 플레이어 기록과 관리자 설정(등록 아이템·보상)을 모두 가져옵니다.

명령어설명
/도감 마이그레이션사용 중이던 스크립트 버전을 자동 감지해 이전
/도감 마이그레이션 2.3도감 2.0~2.3 (variables.csv 저장) 데이터 이전
/도감 마이그레이션 2.4도감 2.4 Beta (플레이어별 yml 저장) 데이터 이전
/도감 마이그레이션 복구되돌릴 내용 미리보기
/도감 마이그레이션 복구 확인이관 전 상태로 정확히 되돌리기
  • 원본 파일은 읽기만 하며 절대 수정하지 않습니다.
  • 스크립트 데이터가 기준입니다 — 원본에 있는 플레이어의 기록과 관리자 설정(등록 아이템·보상·보상금)은 플러그인에 이미 있는 값을 덮어씁니다.
  • 덮어쓰기 전 상태를 자동으로 기록해 두므로, 복구 로 이관 전 상태 그대로 되돌릴 수 있습니다. (복구 시 이관 이후에 진행된 도감 기록도 함께 사라집니다)
  • 구버전 아이템은 현재 서버 버전에 맞게 자동 변환됩니다.

문구 수정 (언어팩)

플레이어에게 보이는 모든 문구는 lang/ko.yml 과 lang/en.yml 에 들어 있습니다. 기본 언어는 영어(en) 입니다. 한국어 서버는 config 맨 위의 language 값을 ko 로 바꾸고 /도감 리로드 하세요. 언어를 바꾸면 config 의 설명 주석도 그 언어로 함께 바뀝니다.

파일을 열어 문장과 색코드를 원하는 대로 고친 뒤 /도감 리로드 하면 바로 반영됩니다. 고쳐 둔 문구는 플러그인을 업데이트해도 그대로 유지되고, 새 버전에서 문구가 늘어나면 빠진 항목만 자동으로 추가됩니다. 번역이 빠진 항목은 한국어로 표시됩니다.

폴더 구조

plugins/EncBook/
├─ config.yml   모든 설정 (카테고리·오프셋·글리프·자동화 옵션)
├─ lang/        표시 문구 (ko.yml)
├─ data/        도감 카탈로그 · 플레이어 데이터(DB) · 마이그레이션 복구 장부
└─ content/     콘텐츠 설치 상태 · 수정 파일 백업

data 폴더가 서버의 도감 데이터 전부입니다 — 백업 시 이 폴더를 보관하세요.
