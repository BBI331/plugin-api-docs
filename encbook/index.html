도감 플러그인 가이드

EncBook 3.0 — 아이템 수집 도감 + 카테고리·진척도 보상

요구 환경

  • 필수 : Paper 1.21.4 이상 (Spigot/바닐라 미지원) · Java 21 이상
  • 필수 : ItemsAdder 또는 Nexo 중 하나 (유료) — 둘 다 없으면 플러그인이 비활성화됩니다
  • 선택 : Vault + 경제 플러그인 (EssentialsX 권장) — 등록·완료·진척도 보상금 지급에 사용

스크립트 버전(도감 2.x)과 달리 Skript 및 애드온이 필요하지 않습니다. 데이터는 자체 데이터베이스에 저장되어 도감을 열 때 파일을 읽지 않아 빠르게 동작합니다.

설치

  1. encbook.jar 를 서버의 plugins 폴더에 넣습니다.
  2. 서버를 시작(재시작)합니다 — ItemsAdder(또는 Nexo) 콘텐츠가 자동으로 설치되고, 리소스팩 재생성(/iazip)까지 자동 실행됩니다.
  3. 리소스팩 재적용 후 /도감 으로 확인하면 끝!
업데이트 : 새 jar 로 교체하고 재시작하면 콘텐츠·설정이 자동 갱신됩니다. 직접 수정한 콘텐츠 파일은 덮어쓰지 않고 보존합니다. PlugMan 리로드도 안전합니다.

명령어

명령어설명
/도감도감 페이지를 오픈합니다
/도감 설정등록 아이템·보상 설정 인터페이스 (관리자)
/도감 조회 <플레이어>특정 플레이어의 도감 조회·수정 (관리자)
/도감 초기화 <플레이어 | *>도감 진행 상황 초기화 (관리자)
/도감 아이템지급 깃펜 <개수> <플레이어>비비의 깃펜(슬롯 해금권) 지급 (관리자)
/도감 리로드config.yml 다시 불러오기 (관리자)
/도감 마이그레이션 [2.3|2.4|복구]구버전 스크립트 데이터 이전 (관리자) — 아래 참고
/도감 정보도감·서버·Java 버전, IA/Nexo·Vault 인식 상태 (관리자) — 문의 시 캡처해서 보내주세요

관리자 권한 노드 : encbook2.admin (기본값 OP)

기존 스크립트(도감 2.x)에서 데이터 이전

기존에 도감 스크립트(2.2 ~ 2.4 Beta)를 사용했다면, 같은 서버에서 명령어 한 번으로 플레이어 기록과 관리자 설정(등록 아이템·보상)을 모두 가져옵니다.

명령어설명
/도감 마이그레이션사용 중이던 스크립트 버전을 자동 감지해 이전
/도감 마이그레이션 2.3도감 2.0~2.3 (variables.csv 저장) 데이터 이전
/도감 마이그레이션 2.4도감 2.4 Beta (플레이어별 yml 저장) 데이터 이전
/도감 마이그레이션 복구되돌릴 내용 미리보기
/도감 마이그레이션 복구 확인이전으로 들어온 데이터만 정확히 삭제
  • 원본 파일은 읽기만 하며 절대 수정하지 않습니다.
  • 여러 번 실행해도 안전합니다 — 이미 있는 기록·설정은 덮지 않습니다.
  • 구버전 아이템은 현재 서버 버전에 맞게 자동 변환됩니다.

폴더 구조

plugins/EncBook2/
├─ config.yml   모든 설정 (카테고리·오프셋·글리프·자동화 옵션)
├─ data/        도감 카탈로그 · 플레이어 데이터(DB) · 마이그레이션 복구 장부
└─ content/     콘텐츠 설치 상태 · 수정 파일 백업

data 폴더가 서버의 도감 데이터 전부입니다 — 백업 시 이 폴더를 보관하세요.
